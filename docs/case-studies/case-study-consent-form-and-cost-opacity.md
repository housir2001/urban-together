# 案例研究（去識別化）：同意書空白欄位與共同負擔不透明

> 擬提交至 `eaprica/urban-together` 的 PR 草稿，對應研究網站「01 專案背景」與「04 研究議題」章節。
> 依本專案協作原則第4點「以證據支持討論，清楚區分事實／研究發現／待驗證假設」撰寫。
> **案例已去識別化**：不具名社區、實施者（建商）、地址、個人姓名；時間僅保留月份，不含年份與確切日期，避免可被反查識別。

## 案例背景（事實，當事人提供第一手經驗）

台北市某一都市更新案，權利變換階段，由一名地主／住戶實際參與推動委員會運作所記錄之經過（當事人陳述）。案件規模中大型，實施者為專營都更之建設公司。

## 觀察到的現象（以下各項為當事人陳述之事實，建議後續以其他案例交叉驗證是否具普遍性）

### 現象一：法定同意書的關鍵欄位留白

據當事人陳述，實施者曾請住戶簽署一份名為「都市更新事業事業計畫同意書」的文件，其中「預估更新後分配之權利價值比率」欄位留白；無法確認其法律效力，其確切定性須視文件實體內容而定。對外說明時，實施者代表將此文件定性為「問卷調查」或「意願確認」，表示沒有拘束力（當事人陳述，未見原始文件）。

**相關法規**：《都市更新條例》第37條第4項規定，所有權人對於公開展覽之計畫所載分配比率，若低於出具同意書時之比率，得於公開展覽期滿前撤銷同意。若簽署同意書時分配比率即為空白，將使公展期間比對「分配比率是否真的比簽署時更差」產生高度舉證困難，個案仍須依撤銷時程及民法（錯誤、傳達錯誤、詐欺脅迫等）與都更條例之具體要件個別判斷，並非當然完全喪失撤銷權。（[全國法規資料庫](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0070008&flno=37)）

**研究提問**：同意書分配比率留白是個案偶發，還是業界普遍操作模式？是否應該在制度上（例如地方自治條例或同意書官方格式）強制要求載明，而非留待個案自律？

### 現象二：共同負擔計算邏輯不公開

實施者對外宣傳以「依市府標準提列」概括帶過，但「營造工程單價」「估價與規劃設計費」「人事行政管理費」「建商風險管理費」等細部計算邏輯與金額，長期未對地主公開。

**法規依據**：各地方政府訂有共同負擔提列基準函釋／行政規則（名稱略有差異，例如臺北市為「都市更新事業及權利變換計畫內有關費用提列總表」、新北市與桃園市均為「都市更新權利變換計畫提列共同負擔項目及金額基準」），風險管理費率並非單一固定數字，而是「基本費率（依規模級距，約10%~14%）」加上「特殊條件加成（如貸款期間超過36個月，每超過1個月加計基數2%）」後，再受各縣市法定上限限制：臺北市、桃園市上限16%（一成六），新北市上限14%（2021年9月由12%調高）。各縣市、各年度版本與計算級距不盡相同，採用時應註明適用之縣市與版本依據（[臺北市都市更新處·費用提列總表](https://uro.gov.taipei/News_Content.aspx?n=F511910B5A36351D&s=EF9B8746E465B226)、[新北市政府函釋](https://www.ntpc.gov.tw/ch/home.jsp?id=e8ca970cde5c00e1&dataserno=91e2146fd2c689b68df79604b94b2be8)、[桃園市政府107年6月5日府都住更字第10701159801號令](https://uract.nlma.gov.tw/uploads/rule/B31041070614200000.pdf)）。

**研究提問**：共同負擔細項是否應有強制公開揭露義務？若建商的利潤提列方式與總成本連動（成本提列費用越高，建商可抽取的管理費也越高），是否存在誘因上的結構性利益衝突，值得制度設計介入？

### 現象三：關鍵承諾不入正式合約

說明會現場提出的具體找補單價、優惠條件，當住戶要求將其寫入正式合約草案時，實施者改稱「僅供參考，非最終依據」。

**研究提問**：是否應建立「說明會承諾與正式合約一致性」的揭露機制，例如要求重大承諾若於公開場合提出，須同步留下書面紀錄並說明若合約未採納時的具體理由？

### 現象四：住戶異議被定調為「內部利益分歧」

部分住戶（如特定樓層或商用空間所有權人）針對分配比例、商業價值估算提出異議時，實施者傾向將爭議定調為「所有權人彼此之間的利益拉扯」，而非正面回應估算方法本身的合理性。

**研究提問**：當爭議本質可能源自估價方法論或資訊揭露不足時，制度上是否該有獨立於實施者的第三方管道，先行釐清「這是方法論爭議還是純粹利益分配爭議」，再進入住戶內部協商，避免實施者藉此迴避對估算方法本身的檢驗？

### 現象五：搬遷費和租金補貼的來源待確認

住戶每戶搬遷費與租金補貼，於簡報中被實施者描述為「建商釋出的福利與誠意」。

**相關法規**：《都市更新權利變換實施辦法》第19條第1項第5款明定，拆遷安置計畫所定之「拆遷安置費」屬權利變換費用（即共同負擔）之一部分（[全國法規資料庫](https://law.moj.gov.tw/LawClass/LawSingle.aspx?Pcode=D0070025&FLNO=19)）。惟簡報所稱之「搬遷費」「租金補貼」是否即為法規所指之「拆遷安置費」、是否確實已列入本案核定之權利變換計畫共同負擔項目，須以該案核定計畫書內容為準，本研究尚未取得該文件，**此處先標記為待確認，不逕自推定其資金來源**。

**研究提問**：此類費用的資金來源說明方式（是否為共同負擔項目、或建商自有資金）是否普遍不透明？是否應建立標準化的住戶教育資料，清楚說明各項費用之構成與資金來源，避免資訊落差造成住戶誤解實施者的讓利幅度？
